# DP.M.341 — Два независимых таймера сессии: бездействие и абсолютный срок

## Обещание

Сессия завершается предсказуемо как для пользователя (при бездействии), так и для системы безопасности (абсолютный потолок), независимо от того, была ли активность.

## Определение проблемы

Один таймер сессии (только бездействие) не закрывает непрерывно активную сессию — уязвимость для похищенного токена или «забытого» браузера. Один абсолютный таймер прерывает реальную работу пользователя без предупреждения.

## Два таймера

| Таймер | Сбрасывается активностью? | Назначение | Рекомендуемое значение |
|--------|---------------------------|------------|------------------------|
| **Бездействие** | Да | Закрывает «забытую» сессию | 30 мин (GLI-19 §2.5.4) |
| **Абсолютный срок** | Нет | Security backstop от вечных сессий | 8 ч (OWASP для приложений «на весь день») |

## IPO-паттерн

| Элемент | Описание |
|---------|----------|
| Входы | Аутентифицированная сессия с activity-событиями |
| Обработка | Таймер бездействия сбрасывается каждым activity-событием; абсолютный не сбрасывается никогда |
| Выходы | Сессия закрывается при первом истечении любого из таймеров |

## Важное свойство

Истечение сессии не должно прерывать незавершённую атомарную операцию (игровой раунд, транзакцию). Операция должна быть: (а) доиграна до конца и результат сохранён, или (б) атомарно отменена с возвратом состояния.

## Когда применять

- Веб-приложения с аутентификацией
- API с долгоживущими access token'ами
- Mobile backends
- Игровые сессии с безопасностью (GLI/OWASP-compliant)

# DP.M.336 Адаптивная плотность сетки

## 1. Определение

Сетка с опциональными полями применяет разные стратегии плотности в зависимости от viewport: фиксированная структура на мобайле (для выравнивания при вертикальном сканировании), максимальная информационная плотность на десктопе (content-fit + удаление пустых ячеек).

## 2. Проблема

Карточки с опциональными полями (заклинания, инвентарь, товары, медкарты) имеют переменное наполнение. Единая стратегия не работает: фиксированная сетка на десктопе теряет пространство на пустых ячейках; content-fit на мобайле ломает вертикальное выравнивание при быстром визуальном сканировании списка.

## 3. IPO-паттерн

| Элемент | Описание |
|---------|----------|
| Входы | Набор карточек с опциональными полями; ширина viewport |
| Обработка | Мобайл: фиксированное количество колонок — все ячейки в потоке, значения выровнены по вертикали. Десктоп: `grid-auto-columns: max-content` — ячейки под контент; пустые ячейки (поле отсутствует) удаляются |
| Выходы | Сетка с максимальной читаемостью под каждый viewport |

## 4. Шаги метода

1. Определить, какие поля опциональные
2. На мобайле: задать фиксированное число колонок в CSS grid; пустые ячейки оставлять (стабильное выравнивание)
3. На десктопе: применить `grid-auto-columns: max-content` / `fit-content`; при отсутствии значения — убирать ячейку из потока (`display: none` или условный рендер)
4. Переключать стратегию через CSS-breakpoint

## 5. Применимость

Карточки и списки с опциональными полями: статы персонажа, инвентарь, карточки товаров, медкарты, профили пользователей. Ключевое наблюдение: мобайл сканируется взглядом вниз по колонке → нужно выравнивание; десктоп сканируется по площади → нужна плотность.

## 6. Forces

| Полюс | Полюс | Напряжение |
|-------|-------|------------|
| Ровный столбец для чтения сверху вниз | Плотность, чтобы больше влезло на экран | Выравнивание тратит место на пустые ячейки, плотность ломает вертикальное сканирование |
| Одна вёрстка (проще поддерживать) | Две стратегии по ширине экрана (лучше читается) | Каждая стратегия добавляет ветку стилей и тестов |

## 7. Bias-Annotation

| Смещение | Направление искажения |
|----------|------------------------|
| Перенос десктопного решения на мобайл | Плотная раскладка, удачная на широком экране, переносится на телефон, где взгляд идёт вниз по колонке и нужно выравнивание |

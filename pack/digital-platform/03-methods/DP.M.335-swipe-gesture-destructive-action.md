# DP.M.335 Свайп-жест для деструктивного действия

## 1. Определение

Паттерн взаимодействия для touch-интерфейсов с деструктивными числовыми операциями. Горизонтальный свайп накапливает подписанный дельта; preview отображается в реальном времени с учётом бизнес-правил; изменение фиксируется только при отпускании пальца; после — кратное окно отмены.

## 2. Проблема

Touch-интерфейсы с деструктивными операциями (урон, трата ресурсов, изменение баланса) применяют изменение немедленно или требуют подтверждения в отдельном диалоге. Первый подход не оставляет времени на осмысление; второй добавляет лишний шаг. Пользователь хочет видеть последствие до фиксации и иметь быстрый откат.

## 3. IPO-паттерн

| Элемент | Описание |
|---------|----------|
| Входы | Горизонтальный drag-жест; направление (влево/вправо); бизнес-правила ограничений (мин/макс, особые состояния) |
| Обработка | Накопить подписанный дельта → рассчитать preview с учётом правил → при отпускании зафиксировать → запустить таймер отмены |
| Выходы | Изменённое состояние + 5-секундное окно отмены; визуальный feedback над точкой касания |

## 4. Шаги метода

1. При начале drag — начать накапливать дельта (влево: отрицательный, вправо: положительный)
2. В процессе drag — показывать preview над точкой касания с учётом бизнес-правил
3. При отпускании — применить дельта через обработчик (например `applyHpDelta`)
4. Запустить окно отмены (5 с); показать `Undo`-кнопку или обработать `Ctrl+Z`
5. Дублировать жест клавиатурными стрелками (keyboard accessibility)

## 5. Применимость

Любой числовой ввод с быстрой отменой: HP-бар в игре, баланс ресурсов, счётчики (корзина, инвентарь), шкалы состояния. Принцип: не применяй сразу — покажи намерение, дай отменить.

## 6. Forces

| Полюс | Полюс | Напряжение |
|-------|-------|------------|
| Применить сразу (быстро) | Показать результат и дать отменить (безопасно) | Каждый промежуточный шаг замедляет частое действие, но без него ошибка стоит дорого |
| Жест удобен на тач-экране | Нужен равноценный вход с клавиатуры | Жест без клавиатурного дубля исключает часть пользователей |

## 7. Bias-Annotation

| Смещение | Направление искажения |
|----------|------------------------|
| «Отмена заменяет превью» | Окно отмены кажется достаточной защитой, хотя превью предотвращает ошибку до фиксации, а отмена лишь исправляет её после |

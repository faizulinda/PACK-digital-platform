# DP.M.337 — Трёхуровневый каскад конфигурации: встроенное → Default → Скин

## Обещание

Новый скин white-label продукта «работает из коробки» без конфигурации; суперадмин управляет платформенными умолчаниями не трогая встроенные значения; каждый скин переопределяет только то, что ему нужно.

## Три уровня

| Уровень | Кто устанавливает | Область действия |
|---------|------------------|-----------------|
| **Встроенное** | Продукт (разработчик) | Все скины, безопасный fallback-минимум |
| **Default** | Суперадмин платформы | Вся платформа, переопределяет встроенное |
| **Скин** | Управляющий скином | Только свой скин, переопределяет Default |

## Алгоритм выбора значения (per-field)

1. Взять значение из конфигурации **Скина** → если задано, использовать.
2. Иначе взять значение из **Default-конфигурации** платформы → если задано, использовать.
3. Иначе взять **встроенное** значение из описания игры/компонента.

Наследование работает **по полю**, не по объекту целиком: скин может переопределить одно поле и унаследовать остальные.

## Inputs

- Skinnable/white-label продукт с несколькими tenants (скинами)
- Конфигурируемые компоненты (игры, формы, параметры UI)

## Outputs

- Рабочая конфигурация для каждого поля в контексте конкретного скина
- Возможность изменить поведение одного скина без влияния на другие

## Когда применять

- White-label / multi-tenant продукт со скинами или тематическими настройками
- Нужна комбинация: «из коробки работает» + «платформа задаёт умолчания» + «скин переопределяет нужное»

## Когда НЕ применять

- Один tenant — достаточно двух уровней (встроенное + переопределение)
- Все скины должны иметь одинаковую конфигурацию — хватает Default

## Антипаттерн

Скин копирует всю конфигурацию Default при создании → при изменении Default скин остаётся на старых значениях; drift детектируется только вручную.

## Forces

| Полюс | Полюс | Напряжение |
|-------|-------|------------|
| Скопировать умолчания в скин (просто, наглядно) | Наследовать по полю (изменения доходят) | Копия видна целиком, но отрезает скин от последующих изменений Default |
| Гибкость переопределения на каждом уровне | Прозрачность итогового значения | Чем больше уровней, тем труднее понять, откуда пришло значение |

## Bias-Annotation

| Смещение | Направление искажения |
|----------|------------------------|
| Иллюзия полной настройки | Скин считается настроенным целиком, хотя часть значений унаследована сверху → источник значения не проверяется, изменение Default неожиданно меняет скин |

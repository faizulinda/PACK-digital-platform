# DP.SOTA.035 Desktop Layout: Rail + Tabbed Workspace

## Проблема

Три равноширинные колонки на десктопе дают «башни разной высоты» при смешанном по объёму контенте: короткая колонка пустеет снизу, длинная уходит за экран. При скролле колонки пользователь теряет постоянно нужные данные из других колонок.

## Решение

Разделить интерфейс по частоте обращения к данным:

| Зона | Содержимое | Поведение |
|------|-----------|-----------|
| **Header** (закреплённый) | Идентификатор + контрольные действия | Всегда виден сверху |
| **Rail** (фиксированная колонка) | Постоянно нужные данные (атрибуты, сохранения, навыки) | Всегда видна, не скроллится с вкладкой |
| **Tabbed workspace** | Контекстуальные секции (Combat / Inventory / Features) | Каждая вкладка скроллится независимо |

Активируется от 1200px и высоты окна ≥700px; меньше — вертикальный стек или tabs без rail.

## Результат (DS-RollKeep, 2026-10-16)

Устранены «башни разной высоты»; постоянно нужные данные (атрибуты, сохранения) всегда видны при работе в любой вкладке workspace.

## Применимость

Data-dense десктопный интерфейс с данными разной частоты обращения: character sheets, трекеры задач, дашборды, медкарты, формы со сложными секциями.
